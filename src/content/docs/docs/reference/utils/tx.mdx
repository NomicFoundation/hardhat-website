title: tx

---

Utilities to work with transactions. They connect to the network selected with `--network`.

Both take the same arguments:

- `to`: The recipient's address.
- `signature`: The function signature, like `"balanceOf(address)"`.
- `args`: The function's arguments, in order.
- `--data`: The `0x`-hex calldata, instead of a signature and arguments.
- `--from`: The sender's address.
- `--value`: The amount of wei to send, in decimal or hex. Defaults to `0`.
- `--block`: The block whose state to use. Defaults to `latest`.

## tx call

Calls a contract without sending a transaction, and prints what it returns.

If the signature includes the return types, like `"balanceOf(address)(uint256)"`, the result is decoded and printed one value per line, with addresses checksummed and arrays and tuples as JSON. Otherwise, the raw return data is printed as hex.

```console
$ npx hhu tx call 0x1f9840a85d5aF5bf1D1762F925BDADdC4201F984 "balanceOf(address)(uint256)" 0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266 --network mainnet
0
```

## tx estimate

Estimates the gas that a transaction would use, and prints it in decimal.

```console
$ npx hhu tx estimate 0x1f9840a85d5aF5bf1D1762F925BDADdC4201F984 "approve(address,uint256)" 0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266 1000 --network mainnet
47198
```
